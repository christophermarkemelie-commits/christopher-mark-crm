## 🎯 How to Use

1. **Clone the repository** to your local machine
2. **Open `index.html`** in your web browser
3. **Customize content** as needed in the HTML file
4. **Update colors** in the CSS `:root` variables if desired
5. **Deploy** to your hosting provider (GitHub Pages, Netlify, etc.)

## 🌐 Deployment Options

### GitHub Pages
1. Go to repository Settings → Pages
2. Select `main` branch as source
3. Site will be available at: `https://yourusername.github.io/christopher-mark-crm/`

### Other Platforms
- **Netlify:** Drag and drop the folder
- **Vercel:** Connect GitHub repo for auto-deployment
- **Traditional Hosting:** Upload files via FTP

## 🎨 Customization

### Change Brand Colors
Edit the CSS `:root` variables in `styles.css`:
```css
:root {
    --primary-color: #000000;      /* Black */
    --accent-color: #FFD700;       /* Yellow */
    --light-bg: #f9f9f9;
    --dark-text: #333333;
    --border-color: #e0e0e0;
}
```

### Update Content
All content can be easily edited in `index.html`:
- Business name and tagline
- Service descriptions
- About text
- Contact information
